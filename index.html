WARNING ! THIS IS JANK ! WARNING

This is a Proof of Concept.

It was published here AFTER the Bevy Game Jam 7 submission deadline. It is not intended for competition / judging.

It is a minimal porting effort to validate wasm builds and deployment.

You probably want the native desktop builds (Windows, macOS, Linux at the itch.io page.

Be warned! Turn down the volume too, in case (see Help below)

Uses webgl2, should work anywhere with recent graphics cards and drivers. Just basic materials and fullscreen effects. Should run fine, at least until a lot of balls are spawned and not cleaned up.

Help: (wasm specific, see itch page for others))

  • Audio volume may be unexpectedly loud, even at the configured 50% master volume default. The menu UI should give an idea of the levels, using short samples.
  • You can't resize the game window yet. You need to scroll the page in the browser to center it.
  • Use Escape to get menu (and pause) or to release mouse.
  • If mouse focus gets lost while playing, try:
    • Escape to game menu
    • Confirm you control the mouse again (see mouse cursor, moves outside browser)
  • Activate (focus + click) a different toplevel window. Just Alt-Tab is not always enough!
  • Focus and click back on the Fever window.
  • The browser should report "Fever has captured the mouse, press Esc to release" or similar again.
  • A panic / crash, if you hit one, manifests as as time pausing in the game and no longer responding to input. Refresh the browser tab to reload.
  • Same limitations and bugs apply as to the desktop builds (see the itch.io page for known issues)
